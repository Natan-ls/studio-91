# Studio 91 - Proposta de Interface Web 🎥

> Projeto desenvolvido para a disciplina de **Interface Homem-Máquina (IHM)**.

Este repositório contém a proposta inicial (MVP) do site institucional da **Studio 91**, uma produtora audiovisual sediada em Belém-PA, com foco na cobertura da **COP-30** e grandes eventos sociais.

## 🎯 Objetivo do Projeto
Desenvolver uma interface web responsiva que aplique conceitos fundamentais de IHM para resolver o problema de comunicação entre a produtora e seus diferentes stakeholders (Corporativo e Social).

## 🧠 Conceitos de IHM Aplicados

O desenvolvimento foi guiado por três pilares principais:

### 1. UI (User Interface)
* **Cinematic Dark Mode:** Uso de fundo escuro para valorizar o conteúdo multimídia e reduzir o cansaço visual.
* **Hierarquia Visual:** Uso da cor dourada apenas em elementos interativos (botões e links), guiando o olhar do usuário.
* **Tipografia:** Fonte para garantir legibilidade e modernidade.

### 2. UX (User Experience)
* **Navegação Narrativa:** A estrutura da conta uma história (Hero -> Serviços -> Prova Social -> Contato), aumentando a taxa de conversão.
* **Gestão de Expectativa:** Textos de microcopy no formulário de contato ("Retorno em 24h") para atender à heurística de *Visibilidade do Status do Sistema*.
* **Segmentação:** Divisão clara entre serviços "Sociais" e "Corporativos" para atender personas distintas na mesma interface.

### 3. QoE (Quality of Experience)
* **Performance:** Estrutura de código otimizada e uso de imagens comprimidas para carregamento rápido.
* **Acessibilidade:** Contraste adequado entre texto e fundo.
* **Engenharia de Software:** Organização semântica de diretórios (`/css`, `/js`, `/img`).

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Estrutura e SEO.
* **CSS3:** Estilização, Flexbox, Grid Layout e Animações.
* **JavaScript (Vanilla):** Lógica do carrossel (slider) e interatividade.
